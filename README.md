# TCBF2026 味覚診断（ビールMBTI）

つくばクラフトビアフェス 2026（2026年10月16日〜18日・つくばセンター広場）の当日企画「ビールMBTI」の診断アプリです。
8問の質問で、飲み口・苦み・香り・原料の4軸から16タイプを判定し、相性のよいスタイル・真逆のタイプ・会場で出会えるフラッグシップビールを案内します。

- 公開ページ: GitHub Pages（このリポジトリの `index.html`）
- 構成: 単一の HTML ファイル。画像・データはすべて内包し、サーバー処理はありません
- 更新方法: `index.html` を差し替えて `main` に push すると、数分で反映されます
